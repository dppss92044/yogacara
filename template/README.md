# 科判閱讀模板

把《瑜伽師地論》App 的介面抽出來的空白模板。放進一部書的**科判、正文、講記**，執行一個指令，就得到一個同樣介面的網站：卷目次、正文、直書科判、科判圖、搜尋、列印與下載都照舊。

## 三步做出一本書

1. 改 `source/book.json`（書名、代號、講記名稱）。
2. 把資料放進 `source/`：正文與科判寫成 `.txt`；講記放進以標記命名的資料夾（例如 `source/講/`）。
3. 執行：

```
python3 tools/build.py
```

完成後 `index.html`、`sw.js`、`data/book.js`、`data/notes-01.js`… 都會重新產生。把整個資料夾放上 GitHub Pages 就是一個網站。

## 不用指令：在 App 裡匯入

功能列表「其他」→「匯入」，打開匯入頁：

1. 填書名、講記名稱。
2. 選正文與科判的 `.txt`（可一次選好幾個），講記檔各自選。
3. 按「檢查」看卷數、科判數與需要注意的地方，再按「套用並開啟」。

資料只存在這台裝置的瀏覽器裡，不會上傳；換裝置要重新匯入。匯入頁下方「清除匯入，回到內建資料」可以改回來。網址加 `?builtin` 會暫時略過匯入的資料。
要做成給別人看的網站，還是用下面的 `build.py`。

## book.json

```json
{
  "代號": "demo",
  "書名": "示範經",
  "短名": "示範經",
  "版本": "1.0.0",
  "講記": [
    {"標記": "講", "名稱": "講記"},
    {"標記": "補", "名稱": "補充講表"}
  ],
  "關於": "資料來源說明，會顯示在「關於」。"
}
```

- **代號**：小寫英文、數字、`-`。同一個網域放好幾本書時，閱讀位置、設定、離線快取都靠它分開，每本書要不一樣。
- **講記**：最多兩種，各自有一個開關（第一種的位置就是原本的「披尋記」，第二種是「常柏法師釋」）。不需要就刪掉。
- **自動科判**：預設開啟，沒有 `#` 的「甲一、…」行也會被當成科判。如果正文常常以「甲一、」開頭，就寫 `"自動科判": false`，科判行改用 `#` 開頭。

## 正文與科判（source/*.txt）

依檔名排序讀入，一行一段：

| 開頭 | 意思 | 例子 |
|---|---|---|
| `=` | 新的一卷（卷名） | `= 示範經卷第一` |
| `@` | 作者、譯者 | `@ 示範譯者 譯` |
| `*` | 品名、小標 | `* 序品第一` |
| `~` | 偈頌（一行一句） | `~ 偈頌第一句` |
| `#` | 科判（可省略，見下） | `# 甲一、序分（分二）` |
| `> 標記` | 講記，接在上一段後面 | `> 講 這一段的講記` |
| `//` | 備註，不會出現 | `// 待查` |
| 其他 | 正文 | `如是我聞……` |

科判的層級看標號第一個字，自動判斷：

- 壹貳參… → 甲乙丙…癸 → 子丑寅…亥 → 天地玄黃宇宙洪荒…
- 「（分二）」可寫可不寫，App 會自己算；「（分二：自方便品至授記品）」冒號後面會變成小字。
- 沒有標號的科（例如「後序」），在 `#` 後面寫層級數字：甲＝1、乙＝2…，壹＝0。例：`#2 後序`。
- 科判可以跨卷接續：下一卷直接寫「乙二、…」，會接在上一卷的甲層下面。
- 只有科判、沒有正文的部分（例如懸談）也可以，單獨成一卷即可。

## 講記資料夾（自動對到科判）

講記檔放進 `source/<標記>/`，例如 `source/講/01.txt`、`source/講/02.txt`：

- 以「【001】」這類編號開頭的行，是一段講記的開始。
- 每一段裡提到的科判（例如「乙一、華嚴時」）會被找出來，這段講記就接在那一科的正文後面；沒提到科判的段落，接在上一段的同一科。
- 「甲二、別明分五：乙一、華嚴時；乙二、阿含時…」這種列舉不算。
- 從 PDF 或網頁複製的講記，每行固定字數斷行也沒關係，會自動接成段落。

## 從 PDF 轉出來的文字

直書 PDF 轉成文字常常一個字一行、夾著頁碼。先整理：

```
python3 tools/pdf_text.py 轉出來的.txt > source/02-經文.txt
```

整理後請自己看一遍：補上「= 卷名」，刪掉目錄、版權頁等不要的部分。偈頌在 PDF 裡字序常常亂掉，要對照原書修正。

`build.py` 會列出同層跳號的科判（例如「丁一」之後直接「丁三」），多半是轉檔時漏掉或黏到別行，請照提示補上。

## 科判頁（A4 直書）

不用匯入科判表 PDF。`build.py` 依科判樹自動分頁（總表＋別表），每頁的實際排版由 App 依樹狀結構重排，跟瑜伽論 App 的藏經版科判頁同一套方法。

## App 更新後同步介面

模板的介面來自 repo 根目錄的 `index.html`。瑜伽論 App 改版後要同步：

```
python3 tools/derive_shell.py      # 由瑜伽論 App 重新產生 shell/index.html
python3 tools/build.py             # 再產生本書網站
```

任何一處對不上，`derive_shell.py` 會停下來說明，不會產生壞掉的外殼。

## 和瑜伽論 App 的差異

- 只有一個版本（沒有大藏經版／韓清淨版切換）。
- 沒有匿名使用統計。
- 版本紀錄、更新動畫重新開始；第一次開啟只看操作簡介。
- 「卷」這個字目前固定，還不能改成「品」或「集」。
- 字型：App 內附的字型只含瑜伽論用到的字，其他字會用電腦內建的楷體／明體補上，少數字的字形可能略有不同。
