# A．確定現行

## A1. 總原則

- 風格：Apple／iOS 系統風格——簡潔、少框線、圓角、淡色、安靜；非必要不解釋文字。（H002、H017、H064、H085）
- 圓角：工具膠囊**全圓角**；其他元件微圓（欄位外角 12px、卷目次／百卷 10px、浮窗／選單／導覽卡／辭典／匯出卡 14px、科判紙張 6px、輸入元件 8px，來自 v1.75；膠囊統一全圓角來自 v1.83）。**所有類似元件須統一，不得只改一個。**（H122、H141 使用者要求「全部類似的都檢查，統一套用」、H142）
- 選取標題的黃底：微圓角（`.nd.on` 4px、`.kn.on` 5px）。（H150 使用者原話）
- 滑鼠停在功能介面超過 **2 秒**，用小矩形說明框顯示簡單說明；離開、點擊、捲動即消失；特別是功能面板各列。（H150 使用者原話，未驗收）
- 強調色：蘋果黃（選取、滑桿填色、同步標示淡黃）。（H049）
- 動效：安靜、跟手；正常拖曳 1:1；只在邊界阻尼；不用誇張 bounce／旋轉／發光；系統「減少動態」須尊重。（H089 規範，實作程度未驗收）
- 觸控不顯示僅滑鼠可見的 hover 提示；說明框只在 hover 裝置。（H150）

## 脈絡圖介面（2026-10-10；D107 第七十八至八十四輪，未驗收）

- 閱讀器右下圖示距右邊14px、48px方形圓角按鈕、26px心智圖圖示。進圖後同位置同大小保留圖示，加「回主頁」文字；點選回原閱讀位置。
- 右上四個按鈕依序齒輪、問號、全部／返回、列印。全部全覽後字樣改返回，回到進圖時的畫面；旁邊保留圖面加減。齒輪不再放列印或主題，只留卷次、介面兩頁籤。
- 頁頂64px橫列為100個36px圓球卷號、間距8px、字14px，始終單排且可橫向滑動／滾輪。取消五部分／十七地；右上四工具位於圓球列下方，不遮卷號。
- 齒輪兩頁的功能底框統一34px高、9px圓角、文字置左並垂直置中。卷次／層數保留各自標示與加減；介面包含架構、標號、樣式、橫直書、並排、全覽、目前。
- 說明卡固定中央390px高（窄高螢幕限制可用高度），手動列點、上／下步、虛線與必要選單展開。無動畫／示範預覽。同類功能只保留一個代表問號；卷次說明指向單排卷球與卷次範圍選單。當前加減號上方的小問號與真實控制保留。
- 節點小選單「只看這個」在左、列印圖示在右；正常字級可容納的分支直接展開，放不下才提供全部／一部；二者皆100%可讀，不以極小倍率塞入全支脈。取消新增的頁頂橫書淡黃根標籤，圖內選取保留。分支回去還原進圖狀態；小選單位置避開左上選單、右上工具列與返回按鈕。
- 滑鼠在支線上顯示淡灰帶與點擊游標，移開即取消。點線後實際上位標題淡黃、置中偏上，倍率至少100%，保留更大倍率與圖面範圍，不自動展開或裁成五層。
- 拖曳、上下／左右滾輪、方向鍵和縮放限定於實際圖面加有限定位邊距，沒有無盡空白；可容納的小分支完整留在螢幕內。

## A2. 功能選單

- 單一圓角卡片，分組（閱讀：版本、內文、導覽；顯示：介面、字體；其他：匯出、關於），分組內有分隔線、最後一項無線；小標題淡色且不可點。（H097、H108）
- 「功能」標題到「版本」列的空白縮短（標題列高 30px、首組上距 4px）。（H150）
- 版本列值：「藏經版」／「韓版」；選項：「大藏經版」。（H150）
- 電腦：滑過列即在右側浮出子選單，可滑過去點選不跳掉。（H097、H113）
- 按空白鍵可關閉浮窗。（H069）
- 子頁（點進內文、字體等）**不得**再出現「導覽」列。（H145）
