## 第 998 頁與實機限制
韓版第 998 頁在以上設定未重現截圖中的突出／裁切；其文字與支線在 A4 紙內，約 x19.17～180.22 mm、y17.85～265.05 mm。截圖只包含局部，未顯示整個科判欄位或倍率，因此不能確認截圖是紙內溢出、放大後視窗裁切或其他狀態。
放大後紙張超過欄寬時，視窗只呈現部分紙張是原有行為，可橫向拖曳查看；本次不把所有放大畫面強制縮回欄寬。
上述是 Chromium 自動化渲染與操作測試，不能替代 iPhone／iPad Safari 實機。若第 998 頁仍出現問題，需整個科判欄位含倍率的截圖及裝置／操作步驟，才能精確重現。Safari 字型時序、原生選取及觸控縮放仍需實機確認。
