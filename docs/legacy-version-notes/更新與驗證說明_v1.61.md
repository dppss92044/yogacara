# 瑜伽師地論 v1.61

本版接續所提供的 v1.60，不替換藏經／韓清淨原文資料，也保留 v1.60 的直書科判樹狀排版引擎。

## 本版修正

- 點卷 67 的丙九、丁一、丁二、戊一等前段科判，不再因畫面仍露出前卷尾端而被捲動偵測切回卷 66。明確選卷／選科判優先，真正捲動正文後才重新辨識目前卷次。
- 科判定位帶著目前卷次；承接前卷的科判也保留所選卷次。正文、卷目次、科判共用這個定位；尚未顯示的科判欄會等到顯示後再套用定位，避免在零高度的隱藏欄位中計算錯誤。
- 手機／平板的查辭典按鈕與辭典浮窗移回底部，保留安全區與底部導覽空間，避開原生選字工具列。觸控取消後清除等待放手的狀態，避免查詞一直無法出現。背景的正文更新不再取消尚未完成的查詞等待。
- 科判雙指縮放以所在頁面的手指位置為錨點；放開後維持該位置。縮放期間與剛放開時不觸發長按追溯或相容性點擊；取消／連續縮放會清理暫時 transform 與舊回呼。
- 干支／章節切換重繪目次、正文及已載入的科判頁，保留閱讀位置、科判頁面錨點與目次捲動位置。韓清淨版也可切換章節數字；藏經版沿用 v1.60 已提供的逐條章節科標。
- 手機正文改為一卷的原生捲軸。正常上下閱讀沒有阻尼；到卷末後再往上拉約 64px，放手才進下一卷；短拉回彈，卷首可往回，卷 1／100 不超出範圍。相鄰卷仍能連續讀，無須左右滑動。平板／電腦保留原有跨卷連續捲動。
- 在既有正文上方工具列固定顯示目前卷名，跨卷時同步更新，沒有另加一列或改正文段落間距。
- 修正重新開啟／離線重開時，舊有卷首定位計時器覆蓋已保存閱讀位置的問題；快速選卷會取消尚未執行的手機單擊定位，避免延遲回跳。閱讀位置保存略過不可見頁碼錨點，並在明確定位期間延後補載前卷，避免補載與還原位置競爭。
- 關於、版本紀錄及快取版號同步升級為 1.61（yogacara-v1.61）。

## 實際驗證

以 Chromium 觸控／螢幕模擬驗證，並非 iOS Safari 實機測試：

| 配置 | 尺寸 |
| --- | --- |
| 手機直向／橫向 | 390×844／844×390 |
| iPad 直向／橫向 | 768×1024／1024×768 |
| 電腦窄／寬視窗 | 900×700／1440×900 |

兩套資料皆檢查卷 67 前六個科判實際點擊、不跨卷、目次標示及網址卷次；卷 56、1、100、67 的選卷與隱藏／顯示科判定位；干支／章節按鈕切換；兩指保持後放大到 150% 並放開，頁內錨點偏差小於 8px；沒有整頁水平溢出。

另以手機模擬遍歷兩版共 200 個卷次及各卷前五個科判定位，檢查卷目次／正文／科判目標；對承接前卷的目次走實際點擊流程。驗證卷內滑動不換卷、短拉不換卷、卷末拉動放手才進下一卷及卷 100 邊界。

平板橫向與電腦另驗證卷 67→68、67→66 的連續捲動與上方卷名更新。

PWA 使用未注入測試程式的正式檔案，驗證 v1.60→v1.61 自動升級、更新不完整時保留舊版、全部 38 個離線資源與快取中繼資料、離線重新載入並還原閱讀位置、離線切換藏／韓、註釋及卷 100、科判顯示。另以測試專用的下一版本回應確認搜尋輸入期間延後重新載入，離開輸入後再更新；交付檔仍為 v1.61。

驗證結果與測試程式在 tools/。測試用的 __r 狀態入口只注入測試伺服器回應，正式 index.html 不含這個入口。

## 保留項目

原文、兩版資料、註釋資料、字型檔、PDF 與匯出資源均與提供的 v1.60 快取雜湊逐項相符。保留 v1.60 白底配色、Apple 風格控制項、三種裝置的 breakpoint、正文縮排／行距、欄位拖曳、字體功能、搜尋、匯出、版本切換及問題回報。Service Worker 的 network-first、完整安裝檢查、舊資源沿用、離線與安全時機自動更新演算法未更換，僅產生新版本與新雜湊。

## 仍需 iPhone／iPad 實機確認

Safari 原生文字反白與選取把手、拷貝／查詢工具列、鍵盤與地址列伸縮、安全區、系統邊界回彈、雙指縮放手感及旋轉後位置。這些模擬測試不能保證所有 iOS／iPadOS 版本的原生行為與效能；外部佛學辭典內容仍需連網，測試只模擬詞條回應並驗證浮窗。

## 部署

這是完整包。將解壓後的 index.html、sw.js、manifest.webmanifest、icon-192.png、icon-512.png、data/ 一起覆蓋到原本 GitHub Pages 的同一層目錄。不要只上傳 index.html。GitHub 網址尚未由本次工作更新。

修改後再發新版：在專案根目錄執行 python3 tools/build_release.py 新版本號，並同步修改關於與版本紀錄。原 v1.60 更新紀錄保存在「既有版本紀錄_v1.60.md」。
